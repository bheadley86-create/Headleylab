About

Headley Lab is my personal IT homelab and portfolio focused on networking, systems administration, virtualization, Microsoft 365, troubleshooting, and cybersecurity.

The goal of the lab is to build practical hands-on experience by configuring systems, troubleshooting real problems, verifying results, and documenting what I learn.

Selected Projects

VLAN & Inter-VLAN Routing

Configured segmented networks for trusted devices and IoT devices. Tested routing, gateway behavior, DNS access, and device isolation.

DNS & Packet Capture

Configured Pi-hole as a DNS server and used "tcpdump" to verify DNS traffic from segmented networks.

Raspberry Pi File Services

Configured SMB file sharing on BatPi and tested access from Windows and Android devices while troubleshooting authentication and permissions.

CUPS Print Server

Configured BatPi as a network print server and tested printer access using CUPS, IPP, and network printing.

Backup Troubleshooting

Investigated an external HDD that caused mounting and boot problems on BatPi. Isolated the issue to unreliable USB power and moved the primary backup workload to Windows for improved reliability.

Active Directory Lab

Built a Windows Server domain environment with users, groups, organizational units, permissions, DNS, and Windows client systems.
