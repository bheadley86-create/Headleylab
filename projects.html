Networking and Infrastructure

Managed Home Network

Built and administered a centrally managed residential network using a dedicated gateway, managed multi-gigabit switching, Power over Ethernet, wired wireless access points, and centralized device management.

Configured DHCP reservations, separate wireless networks, wired access-point backhaul, VLAN planning, tagged uplinks, access ports, spanning tree, PoE budgeting, and network segmentation for trusted and IoT devices.

VLAN Segmentation and Inter-VLAN DNS

Configured a dedicated IoT VLAN with restricted access to the primary LAN while allowing required DNS traffic to a centralized Pi-hole server over TCP and UDP port 53.

Applied firewall and ACL concepts to preserve segmentation while still allowing shared infrastructure services to be reached across network boundaries.

Pi-hole and Dual-Stack DNS

Deployed Pi-hole as a centralized DNS filtering service for IPv4 and IPv6 clients across the home network.

Enabled IPv6 using ISP prefix delegation, Router Advertisements, SLAAC, and RDNSS, then assigned the Pi-hole server a stable IPv6 address for consistent DNS resolution.

Configured host-based firewall rules for IPv4 and IPv6 DNS traffic and verified that clients could resolve names through Pi-hole over both protocol versions.

IPv6 DNS Troubleshooting

Diagnosed an issue where IPv6 ping to the Pi-hole server succeeded but DNS queries timed out.

Used local DNS testing, TCP port testing, packet capture, and firewall inspection to isolate the failure.

Verified that DNS requests were reaching the Linux server with tcpdump, confirmed TCP port 53 was blocked with Test-NetConnection, identified missing IPv6 UFW rules, corrected the firewall configuration, and verified successful DNS resolution with nslookup and Pi-hole query logs.

Wireless Deployment and Wired Backhaul

Used a Wi-Fi analyzer to evaluate signal conditions and improve access-point placement.

Terminated and installed Ethernet cabling with RJ45 connectors to provide wired backhaul for wireless access points.
