About

Headley Lab documents my hands-on experience with IT support, systems administration, networking, cloud services, virtualization, troubleshooting, and cybersecurity.

Small-Business IT Lab Environment

I built Headley Lab to function as a small-business-style IT environment where systems and services work together instead of being practiced only as isolated labs.

The environment includes Windows Server and Active Directory, Windows and Linux clients, Microsoft 365 Business, Exchange Online, DNS, DHCP, VLAN segmentation, Hyper-V virtualization, SQL Server, file sharing, printing, backups, remote access, and endpoint security.

I use the environment to practice user and group management, permissions, domain joins, network troubleshooting, shared resources, email administration, server deployment, backup verification, firewall configuration, and service troubleshooting.

Goal: Build practical experience administering and supporting an environment similar to what an entry-level IT associate, junior systems administrator, or network support technician would encounter in a small organization.

Plan → Build → Test → Troubleshoot → Verify → Document
